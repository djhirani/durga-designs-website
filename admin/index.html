Admin Access (Test Mode)

This is a temporary, local/test admin entry point for Durga Designs staff only. It is not connected to the live site and uses a single shared access token while a proper login system is built.

🔒 Your token is kept only in this browser's session storage — it is never written to any file in this project, never logged, and is sent only to Durga Designs' own server-side functions over this connection.

Don't have a token? Tokens are issued locally by whoever is running this project for testing — see .env.example / docs/supabase-setup.md for how ADMIN_ACCESS_TOKEN is configured.

Durga Designs — internal admin test tool. Not part of the public site. No order data is ever shown without a valid token.
